# Ladrok Start

The home screen of Ladrok TV: the first thing on screen after boot, from which the viewer opens everything else. It follows the Ladrok mantra: only what you need, nothing that shouts, little to set up.

## Language

**Launcher**:
The Ladrok TV home screen. It is the only home screen on the device.
_Avoid_: Home app, start screen, dashboard

**App**:
Something installed on the TV that declares itself as a TV app and can be opened from the Launcher.
_Avoid_: Application, program, channel

**Tile**:
An App's place on the Launcher. Each App has exactly one Tile.
_Avoid_: Card, icon, banner

**Settings Tile**:
The Tile that opens the system settings, always the last one. It is part of the Launcher itself; the system Settings App has no Tile of its own, only lends the Settings Tile its banner.
_Avoid_: Settings button, gear

**Move**:
The viewer rearranging Tiles by hand. It is the only way the order changes.
_Avoid_: Reorder, sort, pin
